# NKSkills visual work

For NKSkills-owned pages or marketing materials, read the root `DESIGN.md`
before changing UI. Keep its color and typography roles aligned with
`site/src/styles/tokens.css`, preserve the approved editorial pastel theme,
and run the site design contract tests after visual changes.

Customer-generated slides and onboarding documents follow the customer's own
brand profile, including `.onboarding/brand/DESIGN.md` when present.
