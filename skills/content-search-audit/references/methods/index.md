# Internal audit methods

These references are part of this one skill, not independently invoked skills.
Load the methods required by each item and stage, retaining a complete rule plan.

- [Content quality](content-quality.md): task usefulness and factual verification.
- [Technical SEO](technical-seo.md): discovery, metadata and technical evidence.
- [AI search readiness](ai-search-readiness.md): platform-specific prerequisites.

- [Generative visibility](generative-visibility.md): actual response observations.
- [Content portfolio](content-portfolio.md): cross-item tasks, gaps and duplication.

Readiness without response observations still requires a visibility measurement
limitation; it does not count as a measured GEO result. Record each method's
applicability and unknowns rather than omitting a dimension silently.
