# Style Contract

- Use the supplied light-only theme and generic design tokens.
- Keep navigation visible on wide screens and reachable by a toggle on narrow
  screens.
- Use cards for grouped concepts, callouts for decisions or risks, and tables
  only for compact comparisons.
- Keep diagrams readable in the default Mermaid theme.
- Use motion only as a subtle orientation aid and preserve a reduced-motion
  experience.
