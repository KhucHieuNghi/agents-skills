# NKSkills pastel editorial theme

The [root DESIGN.md](../DESIGN.md) is the project-wide NKSkills visual
contract. This file records the landing-page reference and implementation
decisions; use the root file for shared tokens and rules.

The supplied reference uses a white page, a large pale peach field, bold
geometric type, plum and rose lettering, warm yellow and sky-blue accents, and
an illustration that dominates the first screen. NKSkills takes that visual
language without copying the reference's person, navigation labels, or
marketing-service content.

The idea is specific to this product: **selected upstream skills and original
workflows become one versioned Solution Skill**. The hero's composition board
illustrates that transformation with the real component names from the
codebase-onboarding release. The existing section order, product claims,
locales, prompts, and supported Codex/Claude paths remain intact.

Fraunces Variable sets the large headings, with the softness axis tuned for
the pastel palette. Source Sans 3 Variable sets paragraphs, navigation, cards,
and small interface copy. Both include self-hosted Vietnamese glyphs. IBM Plex
Mono is reserved for prompt, command, and technical annotation content. The
workflow diagram is responsive HTML using the same type and colour tokens as
the rest of the site; its four steps remain
readable on narrow screens. Product previews use the same plum, rose and pastel
surfaces. The hero's floating composition illustration carries the strongest
shadow; other content relies on surface colour and spacing.

`design-taste-frontend` dealt the **One motif** direction (seed `124313811`).
The large pastel field carries the compositional motif and the board shows the
product itself. The sheet's generic blue/black palette and Jost type were
replaced to honor the supplied reference and Vietnamese font coverage. The
site retains headings and factual status labels where removing them would
damage product clarity. There is no stock photography or video because the
product is a versioned skill workflow and no honest footage exists for it.
