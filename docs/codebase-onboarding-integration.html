User and integration guide

Adaptive Codebase Onboarding

Cách giúp engineer hiểu Product/Business, Technical C4 và Operability trước khi nhận một bounded implementation task.

1. Trạng thái capability

Current capability

Skill hiện tại điều tra codebase bằng CodeGraph và RTK, tạo mô hình Product/Business và C4 dựa trên evidence.

Target adaptive workflow

Progressive journey, adaptive inline/subagent routing, local .onboarding/ state và readiness assessment đã được thiết kế nhưng chưa được triển khai.

HTML renderer

Markdown-to-HTML rendering theo standard là dependency target; template và verifier hiện có chưa phải renderer hoàn chỉnh.

Không dựa vào target behavior cho automation production trước khi implementation và acceptance tests tương ứng đã hoàn tất.

2. Cách dùng profile hiện tại

Chạy từ root của repository này:

npm install
npm run dev -- recommend --intent codebase-onboarding
npm run dev -- apply-profile codebase-onboarding --target codex --scope project

Đọc recommendation trước khi apply. Existing target skills không được overwrite ngầm.

3. Mental model

Product and Business

Actors, outcomes, capabilities, vocabulary và business flow.

Technical C4

C1, C2, selective C3 và code path cần cho task đang xét.

Operability

Runtime, data, auth, failures, run, test và debug.

C4 là technical navigation backbone, không thay thế product intent hoặc operational truth.

5. Adaptive execution target

Mode Khi dùng Ownership
Inline Một bounded, sequential investigation track Root điều tra và tổng hợp
Subagent Ít nhất hai track độc lập và runtime hỗ trợ Subagent chỉ trả structured findings
Fallback Multi-agent unavailable hoặc task thất bại Root chạy cùng contract inline

Root luôn sở hữu user interaction, approval, evidence reconciliation, readiness và artifact writes.

6. External access policy

  1. Trình bày connector, purpose, scope và read-only operation.
  2. Chờ user cấu hình credential bên ngoài conversation.
  3. Chỉ truy cập sau explicit approval.
  4. Thiếu access thì tiếp tục code-only và ghi grey zone.

Database mặc định schema/metadata first, bounded query, no mutation và không lưu raw personal hoặc customer data.

Workspace nằm trong target repo nhưng dùng local Git exclude, không sửa tracked .gitignore và không commit mặc định.

8. Integration sequence

Phase Deliverable Gate
A Generic Markdown renderer trong HTML standard Offline, local assets, freshness verification
B Adaptive onboarding workflow và local state Evidence, resume, access và readiness tests
C Catalog profile compose cả hai skills Validate all before first install

Đối chiếu implementation với onboarding skill contract và HTML documentation standard là hai public source-of-truth trong repository.
