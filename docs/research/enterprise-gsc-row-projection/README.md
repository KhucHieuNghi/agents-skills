# GSC supplied row metrics — development checkpoint

The development assembler projects clicks, impressions, CTR and average position from replay-validated supplied Google Search Console rows. Each metric remains at its original page/row grain and retains source evidence. It does not sum rows, create property totals or average CTR/position. Raw query and device values and the locator are not included in customer output; row numbers are opaque within the report, so additional separately authorized mapping is required to identify individual dimensions.

Projection supports one attributed input group as current; competing or expired retained groups are historical, not current. Identical reimports share the original retained representative. Declined/invalid requests withhold the numerical observations. The existing V1 parent contract refuses a revision that drops prior observations, so withdrawal/refusal of an already reported value requires a separately authorized history disposition; it is not silently redisclosed or represented as resolved.

Only final-state queries, recognized response aggregation compatible with any explicit requested aggregation, complete supplied pagination and absent/empty provider metadata are supported. Missing metadata remains unknown. Nonempty metadata and preliminary data are withheld until mapped correctly. The assembler rejects rather than truncates more than 100 distinct-input rows per target. Unsafe integer clicks/impressions are withheld. Explicit zero is distinct from an absent row. Row position and CTR are labeled approximate; exact integer values refer to the supplied row, not a complete site population. Data is supplied, not provider-authenticated; synthetic or real-declared status is disclosed. Pagination exhaustion is not population completeness.

Independent reviewer found and rechecked fixes for unstable aliases, history loss, unsupported preliminary metadata, aggregation mismatches and per-group diagnostics. Sixteen focused tests cover row values, privacy canaries in all three formats, incomplete pages, empty versus zero, precision and budget limits, aliases, competing/expired inputs, parent continuity and fail-closed refusal. GA4 and Bing numeric projection, multi-page execution verification, authorized withdrawal-safe history, mixed-source acceptance, package integration, customer account evidence and commercial release remain open.
