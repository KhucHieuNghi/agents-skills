# Candidate 0.3.32 — browser replay and request ownership

Browser imports now share a pure compiler with a complete retained-capture inspector. The development general assembler can project browser acquisition counts and fixed limitations without treating availability as module acceptance.

## Browser boundary

Original source envelopes now bind their import assessment time and supported importer fingerprint. Inspection compares the full index/evidence metadata and regenerated checks, rule versions and request descriptors. Every browser capture, check and request must be owned. Import inspects before mutation and before save. Cached observation fields formerly ignored in the index now fail exact-shape validation.

Freshness is recomputed at the final assessment time; an older capture can be shown as historical without another import. Refusal and other request states remain independent of freshness/availability. All browser obligations remain unknown; no capture creates a finding or proves conversion, consent, accessibility, performance or usable journeys. Raw source IDs, bodies, transport detail, URLs and plan material are excluded from report projections. Older unsupported importer records require reacquisition or reviewed migration.

## Independent review findings and fixes

The reviewer reproduced a P2 after the first browser implementation: adding a second request with an owned artifact but foreign window/instructions passed because lookup validated only the first match. The fix requires exactly one matching request before descriptor comparison. The regression now rejects before reuse.

A cross-module review reproduced the same defect in performance. It now requires exactly one matching request too. Ordinary measurement requests already rejected duplicates, but a forged measurement-disposition request was accepted even with no retained dispositions. Measurement now compares the complete disposition-scope inventory and requires one request per retained scope, preserving renewal/revocation lifecycle behavior. These fixes are included in the final archive.

The initial local archive was built before review finished and is not the accepted checkpoint. It remains under the parent build directory. All adjacent package receipts refer to the rebuilt final archive under build/enterprise-browser-replay-0332/final; no archive was published or deployed.
