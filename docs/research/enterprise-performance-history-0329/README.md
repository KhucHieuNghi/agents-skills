# Candidate 0.3.29 — complete performance replay inventory

Performance persistence and inspection now share a deterministic compiler for base/row/observation evidence, checks, requests, policy and rule versions. No trusted collector state enters this compiler. The development general assembler consumes inspector-owned projections, enforcing exact final assessment time and retaining historical observations.

## Ownership and chronology

Each evaluation index retains all historical base IDs (maximum 100), plus a separate activation revision. Inspection recompiles the current and historical graphs from original inputs, compares complete evidence metadata/content and rejects any unowned performance artifact. Requests are regenerated and their descriptors compared, preserving lifecycle state instead of treating provided/refused as an assessment pass. The reserved intake request `performance-observations` remains separately owned; an initial regression caught its collision with the module prefix and the exact intake name is excluded from the module-owned request sweep.

The inspector checks scope, supported fingerprints, chronology and lineage. Independent review reproduced a P2: activation could be backdated to the initial run before evidence existed. The fix requires all current/history origins to belong to lineage and occur at or before activation. A separate regression covers legitimate same-clock A → B → A content reuse, where activation is later than the reused content origin. Missing history references and orphan base/row/observation artifacts reject.

Older fingerprints or indexes lacking complete history are not silently repaired. Use separate assessment or reviewed migration. Receipt hashes still do not restore execution authority; live collector results remain outside durable report observations.

## General report integration

The development projector reads only inspected projections, never cached observation objects directly. It preserves current/historical status and supplies explicit source-only, field/lab and causal limitations. Only actual current failed CrUX checks produce findings, excluding the aggregate duplicate. Conservative unknown states remain suppressed. Lighthouse does not become a field finding; TBT is not substituted for INP.

Canonical JSON/Markdown/HTML exclude native source bodies. Historical measurements remain linked to original evidence. The assembler refuses a current performance evaluation with a different final assessment time, requiring reassessment instead of retimestamping. The projector is development-only; the packaged candidate contains the shared compiler and inspector.
