## What was observed

Only QuokkaGuide source declarations provided target URLs in the retained root projections: two labels refer to the same homepage, producing one target per desktop/mobile profile. Two fresh index-control captures observed a direct HTTP200 response and a Googlebot-allowing robots policy. Both noindex-absence checks remain unknown because restricted resources/request failures invalidate complete rendered coverage. These results do not establish actual crawler access, content quality, indexability, indexed state or search performance.

The other methods/sites lack observed targets or complete declarations. They retain unknown and requests for source/rendered evidence or owner language strategy; no multilingual defect is inferred. No alternate-origin expansion, form submission, transaction or website edit occurred.
