# Bing supplied row metrics — development checkpoint

The development assembler projects replay-validated supplied Bing search rows as separate clicks, impressions, average click position and average impression position; it never pools positions or sums rows. [Microsoft's GetQueryStats documentation](https://learn.microsoft.com/en-us/dotnet/api/microsoft.bing.webmaster.api.interfaces.iwebmasterapi.getquerystats?view=bing-webmaster-dotnet) describes top-query statistics and provides date markers, not a guaranteed daily bucket contract. The report shows an explicit declared absolute export scope; the marker is rendered as a UTC instant with a warning that local date and row bucket boundaries remain unverified. Missing/free-text/future scope and future markers are withheld. Query text, locators and arbitrary scope strings are not reproduced.

Mapped Bing AI dashboard inputs remain attributed as supplied mappings, not authenticated provider output or semantically verified interpretation. The projector preserves exact/approximate/range/unknown states, never computes range midpoints, never converts unavailable values into zero and does not equate citations with rankings, traffic, answer-level mention rates or causality. Dates in the declared period must be explicit absolute dates; mapped row dates, if supplied, must be valid and within that period. A future mapping-review timestamp is rejected. Private dimensions, surface text, reviewer, unknown reason and original mapping/source text are not reproduced. [Bing's Topics Portfolio announcement](https://blogs.bing.com/webmaster/2026/10/introducing-topics-portfolio-beta-in-ai-performance/) describes approximate ecosystem metrics and opportunity ranges; this local mapping is not an independently verified product integration.

Provider selections follow existing replay, stable source identity and historical/competing rules. The target-level cumulative row budget is 100; overflow rejects the report instead of truncating. Declined or invalid evidence is withheld, and parent revisions requiring its prior observations fail closed until an authorized history disposition exists. Stored values are supplied, not a live authenticated account, complete search population, AI ecosystem coverage or production result.

Synthetic tests cover separate search position denominators, offset timestamps, absolute versus ambiguous scopes, future markers/reviews and mapped dates, ranges/unknown/zero, private canaries in JSON/Markdown/HTML, stable alias and competing-source parent continuity, and expiry. Independent review identified the risk of treating a date marker as a daily bucket and invalid mapped temporal values; both were corrected. Broader Bing scope semantics, approved mapping provenance, multi-module/real-account acceptance, withdrawal-safe history and commercial release remain open.
