## Next implementation priority

Implement a versioned owner-defined measurement contract and pure GA4/GTM configuration evaluator, then integrate its checks and requests into immutable report revisions. This addresses the spec's event/key-event mapping and tag/trigger/variable dependency requirements rather than extending sandbox mechanics again.

The contract must bind customer, property/container, stream/version, evidence completeness, freshness and expected configuration. Initial checks should distinguish confirmed absent references from incomplete exports; validate expected property/stream/key-event identity and GTM dependency consistency. A matching configuration must never imply runtime collection, consent compliance, accepted lead or settled payment. Missing business definitions produce targeted requests. Clean, defective, partial, stale, conflicting, foreign-scope and adversarial fixtures are required before packaging.

This is the selected next slice, not its implementation or acceptance evidence. Follow with actual runtime acquisition and the [commercial evaluation protocol](website-audit-enterprise-evaluation.md); preserve the full P0–P7 scope.
