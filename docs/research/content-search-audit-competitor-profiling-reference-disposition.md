# Corey competitor-profiling local-reference review

Read both local references (`templates.md`, `tool-reference.md`) and all seven eval
cases at immutable revision `1f837447b20bb6f0e72d87b80ece1c221c362c7d`.
All inventoried file hashes match the [support-source receipt](content-search-audit-corey-support-review.json).
Cases were not executed; provider tools and endpoints were not called or independently
verified. Decision remains reference-only; no extra runtime or inheritance pin.

| Material                                         | Useful comparison                                                           | Boundary                                                                                                                                                                        |
| ------------------------------------------------ | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dated raw captures and update history            | Preserve old evidence and attach a new observation before comparing periods | A new report date does not refresh retained facts; note capture time separately.                                                                                                |
| Profile and comparison templates                 | Separate directly quoted claims, inferred audience and interpretation       | A homepage logo establishes a displayed claim, not current contract status, customer mix or revenue share.                                                                      |
| Provider metrics                                 | Preserve provider, market, observation window and estimated status          | Domain rank, authority, score and traffic are different constructs. The tool-reference equivalence table does not make their values interchangeable or official engine signals. |
| Positioning maps and SWOT                        | Expose the chosen criteria and evidence for relative judgments              | Subjective axes and blank map space do not establish market demand, an ignored segment or a measurable competitive opportunity.                                                 |
| URL discovery and collection                     | Retain discovered URLs, captured surfaces and unresolved coverage           | A map result is not guaranteed complete. Guessed paths and fallback providers cannot silently expand authorized origins or replace the denominator.                             |
| Empty/blocked responses and dynamic placeholders | Report inability to observe the value                                       | An empty scrape does not prove JavaScript is the cause; a zero can be real. Preserve response evidence and check the actual rendering surface before diagnosing.                |
| Tool fallback                                    | Explicitly disclose unavailable capabilities                                | Do not install a provider, create a browser session, scrape cached alternatives or transmit customer data solely because an upstream recipe names it.                           |

Evaluation case 2 explicitly prefers five of twelve requested competitors and a quick
scan. That default conflicts with our full declared-inventory accounting and cannot
be imported. Explicit user scope changes remain possible, but there is no silent
sampling. Case 5 usefully respects a request to skip SEO collection; this must be a
recorded exclusion, not an invented zero or a complete SEO verdict.

Case 6 proposes challenging a claimed customer count using weak traffic/backlink
signals. Those measures do not establish customer counts without a defensible model
and compatible scope; retain the customer assertion as unverified rather than infer
it is false. Case 7's separation of observed absence, inference and unsupported
advantage is useful and already represented in our evidence contract.

Provider tool names, argument shapes, costs and coverage require current primary
verification before use. This review does not certify Firecrawl, DataForSEO,
Ubersuggest, Ahrefs, Semrush or host WebFetch behavior. No provider is mandatory for
the existing offline/supplied-evidence audit. The source's qualitative examples are
not new benchmark labels and no third supported host is introduced.
