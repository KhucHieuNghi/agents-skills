# Content, SEO, AEO and GEO audit (offline, bounded)

## Executive summary
Of the six pages in the supplied dossiers, four have material defects (/monthly, /instructions, /offer-a, and the draft claims about /offer-b), one is clean (/export), and one is unresolved (/dashboard). The A→B observation increase is supported. The A-versus-D causal claim is not. This is a partial audit with no overall score.

**Verification limits:** No tools, files or helpers were available. Quotations come from the supplied dossier text, not from reopened snapshots, and the quote verifier was not run. No engine, index, validator or feature-availability checks were possible. Observation counts are synthetic and reviewer-supplied.

## Clean or unresolved items
- **A→B comparison (clean control):** The sentence "B improved over A in this fixed API cohort" is supported descriptively. The comparison uses the same engine, model label, locale, market and prompts, with every response reviewed. Persistence, population generalization and cause remain unknown, but that does not undermine the recorded increase.
- **/export (clean):** The title matches the page task and includes all three fields. No truncation, performance or character-limit evidence exists, so shortening it would be an optional preference, not a defect.
- **/dashboard (unknown):** The raw HTML has only an empty root div. No rendered snapshot, owner task or readiness signal was supplied, so the content cannot be assessed. Recovery needs an authorized rendered capture, the ready signal and the intended task. Absence of content in raw HTML is not evidence of absence in rendering.
