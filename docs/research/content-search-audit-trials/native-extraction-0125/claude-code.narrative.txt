After the owner-confirmed ready signal (`document.documentElement.dataset.auditReady === 'true'` was present in the dumped DOM), the rendered main element reads `<main id="task">Open Billing.</main>` (audit-output/run-2-reviewed/evidence/ev-render-dom.txt:2). Failed checks: `seo-rendering` and `quality-claims`.
Limits: one headless capture in Chrome 157.0.8103.51 with a fresh temporary profile and default sandbox; other browsers, viewports and repeat runs were not tested. The script was read as text and was not run outside the browser. Recommendation, owner and verification are in the report backlog.
