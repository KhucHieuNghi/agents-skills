# Semantic micro-control after candidate 0.1.23

Five fresh Claude Code sessions wrote a short audit from four embedded development
dossiers, without the custom skill, extra report guidance, tools or browsing.
The host selected its configured model. The rubric was written before execution;
all five reports were read manually. This is a no-guidance control, not a test
of the installed 0.1.23 package or independent acceptance.

## Results

All processes exited successfully. The price correction retained the before-tax
qualifier in all five reports; A/B and D denominators were not confused. One
report used unscoped rich-result prerequisite wording. Several reports introduced
summary/detail inconsistencies or described downstream search/AI effects as if
observed. A render hypothesis explicitly marked unconfirmed is not counted as
an asserted mechanism. The detailed adjudication distinguishes these cases.

The next useful experiment is a report structure separating source observation,
bounded interpretation, exact correction and verification, with the summary
derived from the completed findings. These results do not justify adding more
price or denominator reminders. No package guidance was changed here.

## Evidence and limits

- `review.json`: primary-assistant manual adjudication with exact quotes.
- `rubric.json`: pre-run criteria, excluded from model prompts.
- `rep-N.prompt.txt`, `rep-N.response.txt`, `rep-N.execution.json`: exact inputs,
  outputs and terminal results. Text responses are intentionally unformatted.
- `artifacts.tgz`: raw event streams, stderr, commands, runner and all inputs.
- `validation.json`: archive hash, per-file hashes and byte-equivalence check.

Five repetitions on development material do not estimate general accuracy.
There is no candidate-guidance arm or full installed workflow in this checkpoint.
The prior native 0.1.22 failures remain open; candidate 0.1.23 is unchanged.
