## A. `guide.txt`: seo-canonical applies, pass (declared signals only)

- **Applicability:** the canonical rule applies. The rule's limitation says non-HTML resources can declare canonicals through HTTP `Link` headers, so media type alone doesn't make it not-applicable.
- **Evidence:**
  - The header says `Link: <https://docs.example/guide>; rel="canonical"`.
  - The publisher map names `/guide` as the intended canonical.
  - Captured `/guide` returns 200 with "the same guide text".
- **Outcome:** the declared canonical, the intended canonical and the observed target agree.
- **Limit:** this does not show that Google selected `/guide`. Only "Set region to west" is quoted, so "same text" rests on the dossier's statement.
- **Missing:**
  - sitemap membership
  - internal links
  - any engine-selected canonical
  - the redirect and robots state of `/guide`
