archive installs. No model was pinned. Codex used its read-only sandbox; Claude

Residual precision issues in the Claude output remain visible:

- The introduction says the other 25 registry rules are unassessed, although D/E
  discuss additional quality/AIO concepts. The prompt requested bounded concepts,
  not formal registry artifacts; that numeric coverage statement is too broad.
- D calls facts current although the supplied signed specification has no date.
  Support in the provided evidence is established; external temporal freshness is
  not independently proven.
- C requests any `/notice` variant even though none is declared. This should be a
  conditional evidence request, not an implied required variant.
- E's suggestion that the approved record might be wrong is conditional and does
  not alter its finding, but the scenario already establishes that record as
  authoritative. The extra qualification is unnecessary for this fixture.

Codex distinguishes source declaration from engine selection and retains unknown
retrieval/citation status. It cites dossier locations; these are native relative
links, retained exactly rather than rewritten into a customer report.

and the identical retained fixture are not represented as independent byte-level
