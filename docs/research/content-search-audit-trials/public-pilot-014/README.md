# NKSkills public pilot — frozen candidate 0.1.4

Real public HTTP captures, not synthetic site responses. The sole allowed origin
was https://nkskills.getgroove.me. The declared pilot followed static navigation
from the root, up to 30 captures and depth 5. It did not include external GitHub
destinations, authenticated providers, rendered JavaScript, CMS exports or orphan
page discovery. Missing analytics and AI observations were intentionally retained.

The harness first ran the packaged static-link helper with maxPages=1. Its process
exited successfully with a partial checkpoint. Fresh Codex and Claude Code projects
received byte-identical copies, then used the installed skill to continue discovery,
collect the resulting inventory, persist reviews and generate reports. This is
**budget-stop recovery**, not proof of recovery from a killed process. Absolute
original capture provenance was preserved in the copies, not rewritten.

The installed component digest is
`3c2cc13a071f1dfd5e7a094d397798c987799d9cac8647197abf61e99c32c510`.
Hosts were Codex CLI 0.166.0 and Claude Code 2.1.325, using their configured default
models without a model pin. Codex used workspace-write with network enabled;
Claude allowed the local tools needed for this isolated pilot. Host permissions,
tools, retry configurations and capture times differ: this is workflow evidence,
not a controlled model ranking experiment. The two host runs were sequential.

## Confirmed deterministic refresh gap

Claude attempted to add extracted-text evidence and assign a deterministic pass;
the guard correctly rejected a host-authored deterministic verdict. An independent
probe then attached an identity extraction of the captured text/plain font notice
with **no reviews**. The helper accepted the new evidence, but persisted the old
unknown check and stale reason that extracted-text was missing. Calling the actual
rule evaluator on those same validated artifacts returns pass. This is a missing
refresh path, not a reason to let hosts override deterministic outcomes.

`deterministic-evidence-bundle.json` and `deterministic-evidence-receipt.json` retain
the source binding, input and observed versus recomputed checks. The reproduction
was run outside both host projects after they terminated. Fixing recomputation,
lineage, findings and invalidation requires a new candidate and focused regression
coverage. Frozen 0.1.4 artifacts remain unchanged.
