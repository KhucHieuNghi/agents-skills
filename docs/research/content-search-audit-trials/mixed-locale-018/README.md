# Mixed sources and alternate-locale trial — 0.1.8

Two fresh native sessions used the frozen 0.1.8 package and identical original
synthetic targets. Gold annotations were withheld from host projects. Each prompt
requested a bounded offline snapshot audit and exact discovery receipt, not a full
campaign or inferred live index/visibility measurements. Only Codex and Claude Code
were used; no model was pinned. These are workflow observations, not a controlled
comparison between models or independent human acceptance.

## Known report error

Claude's F2 verification includes: “Then check Search Console international targeting
or index status once an export exists.” Google's [official deprecation notice](https://support.google.com/webmasters/answer/12474899?hl=en)
states that the International Targeting report is deprecated. The primary-source
search result was retrieved during adjudication; a subsequent full-page open timed
out. The proposed International Targeting workflow is therefore recorded as a
reporting error, not silently edited from the archived report. Actual URL index
inspection, if authorized and available, is a separate capability and does not
replace direct comparison of the reciprocal annotations.

The appropriate verification for the supplied defect is to re-read both revised
heads, confirm their intended reciprocal language targets and self-references,
and distinguish those observations from actual indexing. Candidate instructions
already require evidence-backed recommendations, but this trial shows that the
host can still introduce stale product capabilities. A future change should add
an explicit capability-freshness check for proposed verification steps; it must
be tested and released as a new version rather than rewriting 0.1.8.
