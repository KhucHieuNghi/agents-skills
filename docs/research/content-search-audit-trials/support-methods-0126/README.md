# Support-method transfer trial — 0.1.26

Fresh extracted installations on Codex and Claude Code reviewed four synthetic dossiers,
with six material findings and clean controls. Gold annotations were hashed before execution
and were not copied into either model project. The prompt retained the semantic-0125
contract. This tests transfer to competitor claims, measurement windows, regional templates
and editorial evidence; it does not establish causal benefit from any upstream skill.

Neither host produced validator-backed coverage. Codex supplied manual counts of zero fully
audited and four pending; these cannot substitute for the required inventory artifacts.
Claude disclosed manual review but also conflated referral totals with incrementality in
F4's verification instruction. An incrementality test alone cannot establish total referral
volume. Six of its seven Bash calls also did not begin with the required RTK prefix.
Both reports and replies correctly avoided full-completion claims.

The primary agent authored the fixture and adjudicated results. This is neither independent
human acceptance nor a general precision/recall estimate. Six seeded findings map in order
to F1–F6. Quote checks cover only submitted spans, not semantic truth of the whole report.
No package change or release promotion resulted from this trial.

`artifacts.tgz` preserves 34 original files, including event streams, terminal receipts,
prompts, targets, installation locks, reports and quote ledgers. Every archived file was
byte-compared with its original. Installed package trees and the extracted release are
excluded; both installed trees were compared with the unchanged workspace package.
`adjudication.json` records limitations and findings; host quote-replay JSON files record
fresh verification against the original reports. The standalone report and response copies
are intentionally raw and must not be reformatted independently of their receipts.
