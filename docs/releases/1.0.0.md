## Operational limits

The CLI requires Node.js 22 or later; a Node.js 20 smoke test failed because
`execa@10` uses `Set.prototype.union`. The installation path was exercised on
macOS and the CI definition targets Ubuntu. No Windows installation claim is
made for V1's symlink-based dual-host layout. The onboarding workflow needs
`codegraph`, `rtk`, and a valid project
index. A model-level onboarding run against each customer's repository is a
separate acceptance exercise; package tests do not establish the quality of
that repository-specific output.

Distribution access, commercial terms, pricing, customer support, and the
release channel belong to the business workflow. The archives above remain
local until that workflow chooses a delivery method.
