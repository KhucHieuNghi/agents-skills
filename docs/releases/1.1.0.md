## Changes

Onboarding now leads with diagrams. Quick mode requires a business journey,
C1 context, and C2 container view. Standard and Deep add an entity lifecycle,
selective C3 component view, and journey sequence. Markdown keeps editable
Mermaid source; HTML requires a matching accessible inline SVG for each view.
The workspace verifier rejects missing diagrams and unrendered Mermaid-only
HTML. The generic HTML template now starts from an inline SVG figure, rather
than Mermaid text without a bundled renderer. The diagram contract covers
in-process imports, asynchronous partial success, source-backed arrows, and
visual inspection at desktop and narrow widths.

## Verification performed

- `npm run format:check`, `npm run lint`, `npm run typecheck`, `npm test`, and
  `npm run build` passed. The suite passed 123 tests across 18 files.
- Both changed skills passed `agent-skills validate --source . <skill>`.
- Two clean Solution Skill builds produced the same directory digest and archive
  SHA-256.
- The CLI archive installed in offline mode from a local file. The extracted
  Solution Skill installed into an empty project for both hosts. All three
  installed skills passed validation; Claude Code links resolved and the lock
  recorded version `1.1.0` and the three component digests.
- A clean `1.0.1` installation upgraded to `1.1.0` for both hosts.
- A source-only forward pilot produced six rendered views. Desktop and narrow
  screenshots were inspected; the first render exposed a Mermaid state-label
  parse problem and unreadably shrunken mobile views, which were corrected in
  the local pilot and reflected in the diagram contract. Pilot artifacts and
  target identifiers remain outside this release.

## Limits

The verifier checks diagram presence and basic SVG structure, not factual
accuracy or visual quality. Package and installation tests do not prove that a
model will produce correct onboarding on every topology. Behavior remains
`quality-unverified` pending the synthetic behavior scenarios and broader
forward testing. The pilot did not verify live deployment or data state. No
customer distribution or commercial terms are established by this record.
