## Changes

The onboarding contract now checks overview claims against current routes,
service calls, scripts, and tests before journey selection. It records material
document drift, bounds claims about neighboring systems to the visible client
contract, and distinguishes declared commands from commands with verified
results. The usage runbook supports an Understand-only outcome when no bounded
implementation task is known.

The CLI package version also changed because its bundled README now names the
new Solution Skill archive. Release `1.0.0` retains its original bytes and
fingerprints.

## Limits

Package and installation checks do not verify model-level onboarding quality.
Topology behavior remains `quality-unverified` pending the synthetic behavior
scenarios and a private forward test under the evaluation contract. The target
project still needs CodeGraph, RTK, and a valid local index. No customer
distribution or commercial terms are established by this record.
