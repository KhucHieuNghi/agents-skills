# Eraser Icons Quick Reference

This is a curated list of commonly used icons. For the complete icon list (1000+ icons), see `eraser-standard-icons.csv`.

## How to Use Icons

Attach icons to nodes using the `icon` attribute:
```
NodeName [icon: icon-name]
```

Example:
```
WebServer [icon: aws-ec2]
Database [icon: aws-rds]
User [icon: user]
```

## Finding More Icons

1. **Full icon list**: See `eraser-standard-icons.csv` for complete list with categories
2. **Icon search**: Search for service names (e.g., "aws-", "gcp-", "azure-")
3. **Generic icons**: Use general icons like `server`, `database`, `user` when specific ones aren't available

## Icon Best Practices

1. **Match icons to actual technology**: Use `aws-lambda` for Lambda, not just `server`
2. **Be consistent**: Use the same icon type for similar components
3. **Combine with colors**: Differentiate instances with colors when using same icon
4. **Use generic icons for custom services**: If no specific icon exists, use `server`, `database`, etc.

Example:
```
// Good - specific and consistent
ProdLambda [icon: aws-lambda, color: green]
StageLambda [icon: aws-lambda, color: yellow]
DevLambda [icon: aws-lambda, color: blue]

// Also good - using generic icon for custom service
CustomAPI [icon: server, color: purple]
```
